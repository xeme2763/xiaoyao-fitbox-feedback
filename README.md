# Xiaoyao FitBox Feedback

這是「逍堯工坊 FitBox」App 的公開、去敏問題回報倉庫。

App 會先將回報保存於裝置端；使用者確認後，才開啟預填的 GitHub Issue。只有 App 唯一且精確讀回相同的 title、完整 body、report UUID、payload SHA-256、repository URL 與建立時間，才會將本機回報標記為 `delivered`。

送出前請勿修改預填的 title、body 或底部 hidden markers。截圖只保存在裝置端，不會自動上傳。

請勿在 Issue、留言或附件中放入原始照片、作品名稱、聯絡方式、網址、本機／網路路徑、token／密碼／金鑰、客戶資料、STL、3MF、G-code 或其他私人資料。

GitHub receipt 只代表回報傳輸已被精確讀回，不代表問題已修復、實機驗收或產品案件已關閉。安全性問題請依 [SECURITY.md](SECURITY.md) 私下回報。
